# Alex Morgan demo portfolio (fictional, simulated data)
Preview: open index.html in a browser, or run `python3 -m http.server 8000` and visit localhost:8000.
Edit content: the arrays at the top of js/main.js.
Publish on GitHub Pages: 1) Create a public repo, e.g. alex-portfolio. 2) Upload all files (keep index.html at the top level). 3) Settings > Pages > Source: Deploy from a branch, Branch: main, folder /(root), Save. 4) After about a minute the site is live at https://YOUR-USERNAME.github.io/alex-portfolio/
